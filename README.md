# Learning Tarot

A short course for reading the Rider–Waite–Smith deck aloud and justifying every
sentence — with documented history and occult doctrine taught side by side and
always labelled as which is which.

**Read it here: https://kicu.github.io/learning-tarot/**

The site is plain static HTML (`index.html` + `lessons/` + `reference/`, styled by
`assets/`), published with GitHub Pages from the `main` branch.

This repo is also a teaching workspace: `MISSION.md`, `RESOURCES.md`, `NOTES.md` and
`learning-records/` hold the goals, vetted sources and notes behind the lessons.
